# Drover for Android v0.9.0 — Multi-app preview

## العربية

إضافة اختيار Discord وInstagram وSnapchat وSignal، وحفظ الاختيار، وإظهار حالة التثبيت. اختر تطبيقاتك ثم اضغط تشغيل. أوقف الاتصال قبل تغيير الاختيار. يبقى Discord هو الافتراضي عند تحديث النسخة السابقة.

**مهم:** Instagram وSnapchat وSignal في وضع التمرير المحلي التجريبي؛ لم تُختبر مكالماتها على شبكة المستخدم بعد. المعالجة المخصصة الحالية تتعرف على صيغة اكتشاف Discord، ولا تَعِد بفتح مكالمات التطبيقات الأخرى. عند عدم اختيار Discord تُعطّل هذه المعالجة تلقائياً.

لا توجيه لكل التطبيقات: الاختيار الفارغ أو غير المعروف مرفوض. التطبيقات غير المختارة تبقى خارج VPN. لا توكن أو حساب أو روت أو خادم VPN خارجي.

## English

Selectable per-app routing for the installed official Discord, Instagram, Snapchat and Signal packages. Preferences persist; selection is locked while running. Empty/unknown selections fail closed, preventing accidental all-app capture. Discord is the upgrade default.

Other applications use experimental direct TCP/UDP forwarding, not proven voice-unblocking strategies. The optional prelude is enabled only when Discord is selected and matches its specific discovery packet format; this is protocol recognition, not per-packet UID attribution. Counters aggregate selected apps. Real calls, network migration and UI behavior on these apps still require device testing.

Android10+ / ARM64. Development-signed APK, same signing identity as previous updates. Check SHA256SUMS. Complete native license notices remain bundled.
